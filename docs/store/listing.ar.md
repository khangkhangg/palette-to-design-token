# Site to Design Token — صفحة المتجر في Chrome Web Store (العربية)

## العنوان

Site to Design Token

## الوصف المختصر

حوّل أي موقع إلى رموز تصميم: الألوان والخطوط والمسافات والزوايا والظلال والتباين. صدّر CSS وTailwind وFigma وJSON.

## الوصف التفصيلي

تقرأ إضافة Site to Design Token أي صفحة ويب وتحوّل ما تجده إلى نظام تصميم يمكن إعادة استخدامه: ألوان مرتبة حسب الدور، وأنماط الخطوط، وسلّم المسافات، وانحناء الزوايا، والظلال، ونتائج التباين وفق WCAG. انقر أيقونة شريط الأدوات، وراجع النتيجة، وانسخ ما تحتاجه.

ماذا تفعل
- تجد كل لون في الصفحة وتمنحه دوراً: أساسي، تمييز، سطح، نص وحد.
- تعرض الخطوط وسلّم الأحجام مع الحجم والوزن وارتفاع السطر.
- تكتشف أساس المسافات (4 أو 8 بكسل) وقيم الزوايا والظلال المستخدمة.
- تفحص أزواج النص والخلفية وفق WCAG بمستويي AA وAAA وتُظهر ما لا يجتاز الفحص.
- تفتح نظام التصميم كاملاً في اللوحة الجانبية، بمظهر فاتح أو داكن.
- متوفرة بـ 7 لغات: الإنجليزية والصينية المبسطة والهندية والإسبانية والعربية (من اليمين إلى اليسار) والفرنسية والبنغالية.

المجاني وPro

المجاني
- ألوان مع أدوارها، ونسخ أي قيمة منفردة.
- نسخ قائمة الألوان بصيغة hex.
- عرض الخطوط والمسافات والزوايا والظلال.
- نتائج التباين: ناجح وفاشل.
- المواقع المحفوظة: آخر 3.

Pro، فتح لمرة واحدة بسعر 1.49 دولار
- كل ما في المجاني.
- التصدير إلى CSS وTailwind ومتغيرات Figma وJSON وملف DESIGN.md لأدوات البرمجة بالذكاء الاصطناعي، أو ملف zip يضمها جميعاً.
- اقتراحات لإصلاح التباين.
- المواقع المحفوظة: غير محدودة.

الخصوصية

يتم الفحص على جهازك. تقرأ الإضافة ألوان الصفحة التي تختارها وأنماطها فقط عند نقر أيقونتها، ولا ترسل إلى أي جهة أي معلومات عن الصفحات التي تفحصها. الطلب الوحيد عبر الشبكة هو التحقق الاختياري من ترخيص Pro، وهو يرسل مفتاح الترخيص. السياسة كاملة: https://vietnamcos.com/palette/privacy

الاسترداد

جميع المبيعات نهائية. لأن Pro يُفتح فوراً وسعره 1.49 دولار، لا نقدّم استرداداً للمبلغ بعد الشراء.
