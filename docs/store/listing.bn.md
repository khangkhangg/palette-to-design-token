# Site to Design Token — Chrome Web Store লিস্টিং (বাংলা)

## শিরোনাম

Site to Design Token

## সংক্ষিপ্ত বিবরণ

যেকোনো ওয়েবসাইটকে ডিজাইন টোকেনে বদলান: রং, টাইপ, স্পেসিং, রেডিয়াস, শ্যাডো ও কনট্রাস্ট। CSS, Tailwind, Figma ও JSON এক্সপোর্ট করুন।

## বিস্তারিত বিবরণ

Site to Design Token যেকোনো ওয়েব পেজ পড়ে তাতে যা পায় তা থেকে পুনর্ব্যবহারযোগ্য একটি ডিজাইন সিস্টেম তৈরি করে: ভূমিকা অনুযায়ী সাজানো রং, টাইপ স্টাইল, স্পেসিং স্কেল, কোণের গোলাকার ভাব, শ্যাডো এবং WCAG কনট্রাস্টের ফলাফল। টুলবারের আইকনে ক্লিক করুন, ফলাফল দেখুন, যা দরকার কপি করুন।

এটি কী করে
- পেজের সব রং খুঁজে বের করে ভূমিকা দেয়: প্রাইমারি, অ্যাকসেন্ট, সারফেস, টেক্সট ও বর্ডার।
- ফন্ট ও টাইপ স্কেল দেখায়, সাইজ, ওজন ও লাইন হাইটসহ।
- স্পেসিংয়ের ভিত্তি (৪ বা ৮ px) এবং ব্যবহৃত রেডিয়াস ও শ্যাডোর মান শনাক্ত করে।
- টেক্সট ও ব্যাকগ্রাউন্ডের জোড়া WCAG AA ও AAA অনুযায়ী যাচাই করে এবং কোনগুলো ব্যর্থ তা দেখায়।
- সম্পূর্ণ ডিজাইন সিস্টেম সাইড প্যানেলে খোলে, লাইট বা ডার্ক থিমে।
- ৭টি ভাষায় পাওয়া যায়: ইংরেজি, সরলীকৃত চীনা, হিন্দি, স্পেনীয়, আরবি (ডান থেকে বামে), ফরাসি ও বাংলা।
