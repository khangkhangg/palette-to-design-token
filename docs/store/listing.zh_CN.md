# Site to Design Token — Chrome 网上应用店商品详情（简体中文）

## 标题

Site to Design Token

## 简短说明

将任何网站转换为设计令牌：颜色、字体、间距、圆角、阴影和对比度。可导出 CSS、Tailwind、Figma 和 JSON。

## 详细说明

Site to Design Token 读取任意网页，把其中的设计元素整理成可复用的设计系统：按角色归类的颜色、字体样式、间距比例、圆角、阴影以及 WCAG 对比度结果。点击工具栏图标，查看结果，复制所需内容。

功能
- 找出页面上的所有颜色，并划分角色：主色、强调色、表面色、文本色和边框色。
- 列出字体和字阶，包括字号、字重和行高。
- 检测间距基数（4 或 8 px），以及正在使用的圆角和阴影数值。
- 按 WCAG AA 和 AAA 检查文字与背景的配对，并标出不达标的组合。
- 在侧边栏中查看完整的设计系统，支持浅色和深色主题。
- 支持 7 种语言：英语、简体中文、印地语、西班牙语、阿拉伯语（从右到左）、法语和孟加拉语。

免费版与 Pro 版

免费版
- 带角色的颜色，可复制任意单个数值。
- 复制十六进制颜色列表。
- 查看字体、间距、圆角和阴影。
- 对比度通过与未通过的结果。
- 已保存的网站：最近 3 个。

Pro 版，一次性付费 1.49 美元
- 包含免费版的全部功能。
- 导出为 CSS、Tailwind、Figma 变量、JSON、面向 AI 编程工具的 DESIGN.md，或打包成一个 zip。
- 对比度修复建议。
- 已保存的网站：不限数量。
